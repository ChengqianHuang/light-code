# Light Code

Light Code 是基于 Zed 的本地代码编辑器，专注于日常开发。

- 编辑代码：语法高亮、语言服务和代码导航。
- 管理项目：项目侧栏、文件搜索与多项目切换。
- 开发工具：内置终端、Git 集成和扩展支持。
- 自定义界面：图形化设置、主题与快捷键。

## 已移除或停用

- Agent/ACP、AI 模型配置入口和编辑预测。
- 账号登录与在线协作。
- 远程开发与开发容器入口。
- 遥测采集与崩溃上报。
